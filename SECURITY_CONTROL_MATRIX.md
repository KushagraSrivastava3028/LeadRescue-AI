# Security control matrix

Review date: **2026-10-31**. `PASS` below means the stated **local** regression
passed; it does not certify production, compliance, provider approvals, or an
independent penetration test. PGlite runs real PostgreSQL SQL in WASM with synthetic
Supabase `auth.*` interfaces. Hosted Supabase JWT/GoTrue and multi-connection network
behavior remain unverified. The final commands, versions, commit provenance,
browser/build results, and scanner findings belong in `SECURITY_AUDIT.md`.
